# نظام إدارة وحجز المقابلات الشخصية - نموذج محاكاة وزارة الخارجية المصرية 🏛️
**جامعة السويس • موسم 2026 / 2027**

نظام ويب متكامل وسهل الاستخدام لإدارة مقابلات القبول بالكامل لجميع المتقدمين (438 مرشحاً موزعين على 9 لجان وقطاعات تخصصية).

---

## 🌟 أبرز مميزات النظام

1. **حساب مخصص لكل مدير قطاع / لجنة**:
   - تسجيل دخول مستقل لكل رئيس لجنة يفتح له تلقائياً المرشحين التابعين لقطاعه فقط.
   - إمكانية دخول الإدارة العامة / رئيس النموذج لرؤية جميع اللجان والتحويلات والإحصائيات الكلية.

2. **مولد المواعيد الآلي (تقسيم المواعيد تلقائياً)**:
   - يحدد مدير القطاع: اليوم، نوع المقابلة (أونلاين عبر Zoom/Meet أو أوفلاين في الكلية)، وقت البداية والنهاية، ومدة المقابلة الواحدة (مثلاً 15 دقيقة)، والاستراحة.
   - يقوم النظام آلياً بحساب وتقسيم المواعيد وتوليدها فوراً لتصبح متاحة للحجز.

3. **بوابة وروابط حجز مخصصة للطلاب**:
   - رابط مباشر لكل قطاع مثل: `/book/arab` أو `/book/crises`.
   - يبحث الطالب عن اسمه أو رقم هاتفه ويختار اليوم والوقت والنوع (أونلاين أو أوفلاين).
   - يتم حجز الموعد باسمه فوراً وإصدار **بطاقة موعد رسمية (Interview Pass)** مع زر إرسال التفاصيل لنفسه عبر واتساب.

4. **لوحة تحكم كاملة لمدير القطاع**:
   - متابعة لحظية: من حجز، من لم يحجز بعد، من تمت مقابلته، ومن تغيب.
   - زر واتساب مباشر بجوار كل مرشح للتواصل السريع.
   - إمكانية تعديل أو إلغاء موعد أي طالب يدوياً.

5. **نظام تقييم متقدم للمقابلة**:
   - رصد حالة الحضور (حضر / غائب / اعتذر).
   - تقييم من 10 بنجوم وتفاصيل المعايير (التواصل، المعرفة، الالتزام، الإنجليزية).
   - تدوين الملاحظات والقرار المبدئي (مقبول / احتياطي / غير مناسب).

6. **ميزة تحويل المرشح لقطاع آخر (Sector Transfer)**:
   - بضغطة زر واحدة يمكن تحويل المرشح للجنة أنسب مع ذكر سبب التحويل.
   - ينتقل المرشح فوراً لقائمة اللجنة الجديدة ويُتاح موعده القديم للحجز مجدداً مع تسجيل العملية في سجل التحويلات.

7. **تصدير وطباعة**:
   - تصدير كشوفات المرشحين مع درجات التقييم والملاحظات إلى Excel / CSV بترميز UTF-8 سليم للغة العربية.
   - طباعة كشف حضور ورقي منظم للمقابلات.
